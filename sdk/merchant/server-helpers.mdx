The Merchant SDK includes helper functions to easily add X402r refund support to existing x402 server implementations.

## refundable()

Mark a payment option as refundable:

```typescript
import { refundable } from '@x402r/merchant';

const paymentOption = {
  amount: '1000000', // 1 USDC
  token: 'USDC',
  network: 'base-sepolia',
};

const refundableOption = refundable(
  paymentOption,
  operatorAddress,
  {
    escrowPeriod: 86400, // 24 hours in seconds
    refundAddress: refundRequestAddress,
  }
);

// Result includes x402r metadata
console.log(refundableOption.x402r);
// {
//   operator: '0x...',
//   escrowPeriod: 86400,
//   refundAddress: '0x...',
//   isRefundable: true,
// }
```

## withRefund()

Transform all routes in a configuration to support refunds:

```typescript
import { withRefund } from '@x402r/merchant';

const existingRoutes = {
  '/api/premium': {
    amount: '5000000',
    token: 'USDC',
  },
  '/api/basic': {
    amount: '1000000',
    token: 'USDC',
  },
};

const refundableRoutes = withRefund(
  existingRoutes,
  operatorAddress,
  {
    escrowPeriod: 86400,
    refundAddress: refundRequestAddress,
  }
);

// All routes now include x402r metadata
```

## Options

Both helpers accept optional configuration:

```typescript
interface RefundableOptions {
  /** Escrow period in seconds (default: 86400 = 24 hours) */
  escrowPeriod?: number;

  /** Custom RefundRequest contract address */
  refundAddress?: `0x${string}`;

  /** Custom escrow recorder address */
  escrowRecorder?: `0x${string}`;
}
```

## Express Integration Example

```typescript
import express from 'express';
import { refundable, X402rMerchant } from '@x402r/merchant';
import { getNetworkConfig } from '@x402r/core';

const app = express();
const config = getNetworkConfig(84532);

// Payment options with refund support
const paymentOptions = refundable(
  { amount: '1000000', token: 'USDC' },
  operatorAddress,
  { escrowPeriod: 86400 }
);

// Middleware to handle x402 payments
app.use('/api/paid', (req, res, next) => {
  // Check for payment header
  const payment = req.headers['x-payment'];

  if (!payment) {
    // Return 402 with payment requirements
    return res.status(402).json({
      accepts: [paymentOptions],
    });
  }

  // Verify payment and continue
  // ... payment verification logic ...
  next();
});

// Refund webhook endpoint
app.post('/api/refund-webhook', async (req, res) => {
  const { paymentInfoHash } = req.body;

  const merchant = new X402rMerchant({
    publicClient,
    walletClient,
    operatorAddress,
    refundRequestAddress: config.refundRequest,
  });

  // Check if there's a pending refund request
  const hasRequest = await merchant.hasRefundRequest(paymentInfo);

  if (hasRequest) {
    // Auto-approve for this example
    await merchant.approveRefundRequest(paymentInfo);
    await merchant.refundInEscrow(paymentInfo);
    res.json({ status: 'refunded' });
  } else {
    res.status(404).json({ error: 'No refund request' });
  }
});

app.listen(3000);
```

## x402r Metadata Schema

When you use `refundable()` or `withRefund()`, the resulting payment options include an `x402r` field:

```typescript
interface X402rMetadata {
  /** PaymentOperator contract address */
  operator: `0x${string}`;

  /** Escrow period in seconds */
  escrowPeriod: number;

  /** RefundRequest contract address */
  refundAddress?: `0x${string}`;

  /** EscrowPeriodRecorder address */
  escrowRecorder?: `0x${string}`;

  /** Whether this payment supports refunds */
  isRefundable: true;
}
```

Clients can use this metadata to know:
1. The payment supports X402r refunds
2. Which contracts to interact with
3. How long the escrow period lasts

## Full Server Example

```typescript
import express from 'express';
import { createPublicClient, createWalletClient, http } from 'viem';
import { baseSepolia } from 'viem/chains';
import { privateKeyToAccount } from 'viem/accounts';
import { X402rMerchant, withRefund } from '@x402r/merchant';
import { getNetworkConfig } from '@x402r/core';

const app = express();
app.use(express.json());

// Setup
const publicClient = createPublicClient({
  chain: baseSepolia,
  transport: http(),
});

const account = privateKeyToAccount(process.env.MERCHANT_KEY as `0x${string}`);
const walletClient = createWalletClient({
  account,
  chain: baseSepolia,
  transport: http(),
});

const config = getNetworkConfig(84532);
const operatorAddress = '0x...';

// Define routes with refund support
const routes = withRefund(
  {
    '/api/data': { amount: '1000000', token: 'USDC' },
    '/api/premium': { amount: '5000000', token: 'USDC' },
  },
  operatorAddress,
  { escrowPeriod: 86400 }
);

// Create merchant instance
const merchant = new X402rMerchant({
  publicClient,
  walletClient,
  operatorAddress,
  refundRequestAddress: config.refundRequest,
});

// Watch for refund requests
merchant.watchRefundRequests(async (event) => {
  console.log('New refund request:', event);
  // Handle the request...
});

// Payment-protected routes
app.get('/api/data', (req, res) => {
  const payment = req.headers['x-payment'];

  if (!payment) {
    return res.status(402).json({
      accepts: [routes['/api/data']],
    });
  }

  // Payment verified, return data
  res.json({ data: 'premium content' });
});

app.listen(3000, () => {
  console.log('Server running on port 3000');
});
```
