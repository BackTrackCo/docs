The X402r SDK provides a complete TypeScript implementation for integrating with the X402r refundable payments protocol. It enables clients, merchants, and arbiters to interact with smart contracts for payment authorization, escrow management, and dispute resolution.

## Packages

The SDK is organized into four packages, each designed for a specific role in the payment ecosystem:

<CardGroup cols={2}>
  <Card title="@x402r/core" icon="box" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/docs-generated/core/src">
    Shared types, ABIs, and utilities used by all other packages.
  </Card>
  <Card title="@x402r/client" icon="user" href="/sdk/client/quickstart">
    SDK for payers to query payments, request refunds, and manage escrow.
  </Card>
  <Card title="@x402r/merchant" icon="store" href="/sdk/merchant/quickstart">
    SDK for merchants to release payments, handle refunds, and configure servers.
  </Card>
  <Card title="@x402r/arbiter" icon="scale-balanced" href="/sdk/arbiter/quickstart">
    SDK for arbiters to resolve disputes and automate decisions with AI.
  </Card>
</CardGroup>

## Key Features

<AccordionGroup>
  <Accordion title="Type-safe contract interactions" icon="shield-check">
    Built on [viem](https://viem.sh) for fully typed interactions with X402r smart contracts. All ABIs are exported with complete TypeScript types.
  </Accordion>
  <Accordion title="Event subscriptions" icon="bell">
    Real-time event watching for payment state changes, refund requests, and freeze events across all packages.
  </Accordion>
  <Accordion title="AI-ready arbiter SDK" icon="robot">
    Built-in hooks for integrating AI models into dispute resolution workflows with structured evaluation contexts.
  </Accordion>
  <Accordion title="Server helpers" icon="server">
    Express middleware and route helpers for merchants to easily add refund support to existing x402 servers.
  </Accordion>
</AccordionGroup>

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      @x402r/core                            │
│  Types • ABIs • Network Config • Utilities • Conditions     │
└─────────────────────────────────────────────────────────────┘
        ▲                    ▲                    ▲
        │                    │                    │
┌───────┴───────┐  ┌─────────┴─────────┐  ┌──────┴──────┐
│ @x402r/client │  │ @x402r/merchant   │  │ @x402r/arbiter │
│               │  │                   │  │               │
│ Payment Query │  │ Release/Refund    │  │ Approve/Deny  │
│ Refund Request│  │ Server Helpers    │  │ AI Hooks      │
│ Escrow Ops    │  │ Event Watch       │  │ Batch Ops     │
└───────────────┘  └───────────────────┘  └───────────────┘
```
