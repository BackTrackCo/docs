<Warning>
The X402r SDK is in active development (v0.1.0). APIs may change between releases. Always test on Base Sepolia before using real funds on mainnet.
</Warning>

The X402r SDK provides a complete TypeScript implementation for integrating with the X402r refundable payments protocol. It enables clients, merchants, and arbiters to interact with smart contracts for payment authorization, escrow management, and dispute resolution.

## Packages

The SDK is organized into five packages, each designed for a specific role in the payment ecosystem:

<CardGroup cols={2}>
  <Card title="@x402r/core" icon="box" href="/sdk/concepts">
    Shared types, ABIs, network config, deploy utilities, and condition builders.
  </Card>
  <Card title="@x402r/client" icon="user" href="/sdk/client/quickstart">
    SDK for payers to request refunds, freeze payments, and manage escrow.
  </Card>
  <Card title="@x402r/merchant" icon="store" href="/sdk/merchant/quickstart">
    SDK for merchants to release payments, charge, and handle refunds.
  </Card>
  <Card title="@x402r/arbiter" icon="scale-balanced" href="/sdk/arbiter/quickstart">
    SDK for arbiters to resolve disputes, manage registry, and automate decisions with AI.
  </Card>
</CardGroup>

<Card title="@x402r/helpers" icon="wrench" href="/sdk/helpers/refundable">
  Framework-agnostic helper to mark x402 payment options as refundable with escrow configuration.
</Card>

## Key Features

<AccordionGroup>
  <Accordion title="Type-safe contract interactions" icon="shield-check">
    Built on [viem](https://viem.sh) for fully typed interactions with X402r smart contracts. All ABIs are exported with complete TypeScript types.
  </Accordion>
  <Accordion title="Event subscriptions" icon="bell">
    Real-time event watching for payment state changes, refund requests, and freeze events across all packages.
  </Accordion>
  <Accordion title="AI-ready arbiter SDK" icon="robot">
    Built-in hooks for integrating AI models into dispute resolution workflows with structured evaluation contexts.
  </Accordion>
  <Accordion title="One-command deployment" icon="rocket">
    `deployMarketplaceOperator()` deploys all necessary contracts (operator, escrow period, freeze, conditions) in a single call.
  </Accordion>
  <Accordion title="Arbiter registry" icon="clipboard-list">
    On-chain registry for arbiters to register, update metadata, and be discovered by merchants and clients.
  </Accordion>
</AccordionGroup>
