The [x402r-sdk repo](https://github.com/BackTrackCo/x402r-sdk/tree/main/examples) ships runnable examples for every role. Each starts a local Anvil fork, deploys contracts, and runs end-to-end; no wallet or testnet funds needed.

## Examples

<CardGroup cols={2}>
  <Card title="facilitator" icon="handshake" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/facilitator/basic">
    Operator-agnostic HTTP service implementing x402's facilitator protocol. Handles signature verification and on-chain settlement for `authCapture`.
  </Card>
  <Card title="deploy-operator" icon="rocket" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/deploy-operator">
    Deploy a complete marketplace or delivery-protection operator via `deployMarketplaceOperator()` / `deployDeliveryProtectionOperator()`.
  </Card>
  <Card title="server-express" icon="server" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/servers/express">
    Express merchant server using `AuthCaptureServerScheme` and `HTTPFacilitatorClient` to accept refundable payments via x402 middleware.
  </Card>
  <Card title="server-hono" icon="server" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/servers/hono">
    Hono merchant server using `AuthCaptureServerScheme` and `HTTPFacilitatorClient` to accept refundable payments via x402 middleware.
  </Card>
  <Card title="merchant-cli" icon="terminal" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/dev-tools/merchant-cli">
    CLI tool for merchants to capture funds, void / deny / approve refunds, and query escrow state.
  </Card>
  <Card title="client-cli" icon="user" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/dev-tools/client-cli">
    CLI tool for payers to `pay`, `preview-fee`, request refunds, freeze payments, and check status.
  </Card>
  <Card title="arbiter-cli" icon="gavel" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/dev-tools/arbiter-cli">
    CLI tool for arbiters to review cases, deny / refuse / execute refunds, and manage registry.
  </Card>
  <Card title="shared" icon="share-nodes" href="https://github.com/BackTrackCo/x402r-sdk/tree/main/examples/dev-tools/shared">
    Shared utilities for the CLI examples: `parsePaymentInfo`, `shortAddress`, `formatUSDC`.
  </Card>
</CardGroup>

## Running examples

<Warning>
Mainnet runs require funded wallets on Base. For local runs, the Anvil-fork scripts seed accounts automatically.
</Warning>

<CodeGroup>
```bash npm
git clone https://github.com/BackTrackCo/x402r-sdk.git
cd x402r-sdk
npm install && npm run build
```
```bash pnpm
git clone https://github.com/BackTrackCo/x402r-sdk.git
cd x402r-sdk
pnpm install && pnpm build
```
```bash bun
git clone https://github.com/BackTrackCo/x402r-sdk.git
cd x402r-sdk
bun install && bun run build
```
</CodeGroup>

Then run a per-action example:

```bash
pnpm example:payer:request-refund
pnpm example:merchant:charge
pnpm example:arbiter:approve-refund
```

See the [examples directory README](https://github.com/BackTrackCo/x402r-sdk/tree/main/examples) for the full list of scripts.
