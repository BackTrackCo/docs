The `@x402r/core` package exports fully-typed ABIs for all X402r smart contracts.

## PaymentOperatorABI

The main contract for payment operations:

```typescript
import { PaymentOperatorABI } from '@x402r/core';

// Use with viem
const state = await publicClient.readContract({
  address: operatorAddress,
  abi: PaymentOperatorABI,
  functionName: 'getPaymentState',
  args: [paymentInfo],
});
```

### Key Functions

| Function | Description |
|----------|-------------|
| `getPaymentState` | Get current payment state |
| `authorize` | Create a new payment |
| `release` | Release funds to merchant |
| `refundInEscrow` | Refund while in escrow |
| `settle` | Settle released payment |

## RefundRequestABI

Contract for managing refund requests:

```typescript
import { RefundRequestABI } from '@x402r/core';

// Create a refund request
const hash = await walletClient.writeContract({
  address: refundRequestAddress,
  abi: RefundRequestABI,
  functionName: 'requestRefund',
  args: [paymentInfo],
});
```

### Key Functions

| Function | Description |
|----------|-------------|
| `requestRefund` | Create a refund request |
| `cancelRefundRequest` | Cancel your request |
| `updateStatus` | Approve/deny (arbiter/merchant) |
| `hasRefundRequest` | Check if request exists |
| `getRefundRequestStatus` | Get request status |
| `getPayerRefundRequestHashes` | Get payer's requests |
| `getReceiverRefundRequestHashes` | Get merchant's requests |

## EscrowPeriodRecorderABI

Contract for tracking escrow periods:

```typescript
import { EscrowPeriodRecorderABI } from '@x402r/core';

// Check if frozen
const isFrozen = await publicClient.readContract({
  address: recorderAddress,
  abi: EscrowPeriodRecorderABI,
  functionName: 'isFrozen',
  args: [paymentInfo],
});
```

### Key Functions

| Function | Description |
|----------|-------------|
| `freeze` | Freeze a payment |
| `unfreeze` | Unfreeze a payment |
| `isFrozen` | Check frozen status |
| `getAuthorizationTime` | Get auth timestamp |
| `isEscrowPeriodPassed` | Check if escrow expired |

## Example: Direct Contract Interaction

```typescript
import { createPublicClient, createWalletClient, http } from 'viem';
import { baseSepolia } from 'viem/chains';
import {
  PaymentOperatorABI,
  RefundRequestABI,
  PaymentState,
  RequestStatus,
} from '@x402r/core';

const publicClient = createPublicClient({
  chain: baseSepolia,
  transport: http(),
});

// Read payment state
const state = await publicClient.readContract({
  address: '0x...',
  abi: PaymentOperatorABI,
  functionName: 'getPaymentState',
  args: [paymentInfo],
});

console.log('State:', PaymentState[state]);

// Check refund request
const hasRequest = await publicClient.readContract({
  address: '0x...',
  abi: RefundRequestABI,
  functionName: 'hasRefundRequest',
  args: [paymentInfo],
});

if (hasRequest) {
  const status = await publicClient.readContract({
    address: '0x...',
    abi: RefundRequestABI,
    functionName: 'getRefundRequestStatus',
    args: [paymentInfo],
  });
  console.log('Refund status:', RequestStatus[status]);
}
```

## TypeScript Integration

All ABIs are fully typed for viem. TypeScript will infer correct types for function arguments and return values:

```typescript
// TypeScript knows the return type is PaymentState (number)
const state = await publicClient.readContract({
  address: operatorAddress,
  abi: PaymentOperatorABI,
  functionName: 'getPaymentState',
  args: [paymentInfo], // Correctly typed as PaymentInfo
});

// TypeScript will error if you pass wrong arguments
await publicClient.readContract({
  address: operatorAddress,
  abi: PaymentOperatorABI,
  functionName: 'getPaymentState',
  args: ['wrong'], // Type error!
});
```
